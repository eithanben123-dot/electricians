# יוסי ליבוביץ׳ — שמאי מקרקעין מוסמך

Static one-page site (HTML/CSS/JS, Hebrew RTL). No build step: serve the folder (`python3 -m http.server`) or drop it on any static host.

- **Hero**: Higgsfield fly-through (Nano Banana Pro start frame → image-to-image end frame → Kling 3.0 clip).
  Desktop scrubs an all-intra encode with the scroll; screens < 820px play a light ping-pong loop.
- Media (videos, poster, section photos) are hosted on the Higgsfield CDN; the portrait is in `assets/img/`.
- **Contact details**: fill `CONTACT` (phone / WhatsApp / email) at the top of `script.js`;
  optional `FORM_ENDPOINT` for the lead form. Empty values make the buttons scroll to the form.
