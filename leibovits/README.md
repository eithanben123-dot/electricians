# יוסי ליבוביץ׳ — שמאי מקרקעין מוסמך · "Onyx & Brass"

Static one-page site (HTML/CSS/JS, Hebrew RTL), no build step. Serve the folder (`python3 -m http.server`) or drop it on any static host.

- **Hero**: Higgsfield night fly-through (Nano Banana Pro start frame → image-to-image end frame → Kling 3.0, 8 s).
  Desktop scrubs an all-intra encode with the scroll (+ letterbox bars, HUD timecode, scroll-linked zoom);
  < 820px plays a light ping-pong loop.
- **השיטה** (`gl.js`, Three.js via CDN import map): 16k brass particles morph with the scroll —
  data cloud → cadastral parcels → building wireframe.
- Services: pinned horizontal gallery (native swipe on mobile), 3D tilt cards, looping Kling clip of a plaster model.
- Lenis smooth scroll, custom cursor, magnetic buttons, masked line reveals, word-by-word statements, film grain.
- Media live on the Higgsfield CDN; the portrait is in `assets/img/`.
- **Contact details**: fill `CONTACT` at the top of `script.js` (optional `FORM_ENDPOINT`).
