# AETHER — site 3D pour une agence IA & Web (hébreu, RTL)

Un monde WebGL continu (Three.js) que la caméra traverse au scroll. Tout est procédural : shaders, géométries et textures générées en code (aucun fichier 3D ni vidéo).

| # | Section | 3D |
|---|---|---|
| 01 | Hero | Noyau IA liquide (shader de bruit) dans une coque de verre irisé, anneaux orbitaux, éclats chrome, téléphone et tablette flottants. Réagit au curseur, clic = onde de choc. |
| 02 | Services | Trio flottant : sphère neuronale (agents), laptop avec site qui défile (web), engrenages + tuyaux à impulsions (automatisation). |
| 03 | Agents IA | Réseau neuronal vivant (signaux qui voyagent), 4 orbes-agents reliés par synapses. Terminal de chat animé par agent. |
| 04 | Portfolio | Carrousel 3D de 5 appareils (laptop/téléphone/tablette) aux écrans animés ; clic = rotation vers le projet. |
| 05 | Process | Vol à travers un tunnel de données et 4 portes lumineuses. |
| 06 | Bénéfices | 9 000 particules qui se transforment : sphère → cube → anneau → double hélice ; elles fuient le curseur. |
| 07 | Labo | Objet à faire tourner à la souris, 3 modes (noyau liquide / verre / réseau). |
| 08 | Contact | Portail vortex + formulaire (ouvre l'e-mail pré-rempli). |

Lancer : `python3 -m http.server 4190` dans ce dossier → http://localhost:4190
